# Qoʻlyozma — Android (WebView)
`MainActivity` ichida WebView `assets/index.html` ni ochadi. PDF/PNG saqlash `QAndroid` ko‘prigi orqali tizim "Saqlash" oynasi (CREATE_DOCUMENT) bilan ishlaydi.
Qurish: `PW=<keystore paroli> ./build.sh` (keystore repoga qoʻyilmaydi!).
Veb versiyani yangilasangiz, `assets/index.html` ni qayta tayyorlang (jsPDF lokal: `jspdf.umd.min.js`, saqlash qismi `QAndroid` ga ulangan).
